# Portal de documentação com Astro + Starlight

Experimento de apresentação navegável da biblioteca técnica do repositório, inspirado na organização por assuntos de portais como Invokta. O GitHub permanece como fonte oficial.

## Desenvolvimento

```bash
cd site
npm install
npm run dev
npm run build
```

Para hospedar em subdiretório: `DOCS_SITE_URL` e `DOCS_BASE_PATH`. Leia [publicação do portal](../docs/site/DEPLOY-DOCS.md).
