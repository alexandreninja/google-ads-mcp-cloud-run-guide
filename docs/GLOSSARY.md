# Glossário

| Termo | Significado |
| --- | --- |
| MCP | Protocolo para conectar aplicações de IA a ferramentas |
| STDIO | Transporte por entrada/saída de processo |
| Streamable HTTP | Transporte MCP sobre HTTP |
| OAuth 2.0 | Padrão de autorização |
| GAQL | Google Ads Query Language |
| MCC | Conta de administrador do Google Ads |
| IAM | Gestão de identidades e permissões |
| TCO | Custo total de implantação e operação |
