# Glossário

| Termo | Explicação |
| --- | --- |
| MCP | Protocolo para aplicações de IA se conectarem a ferramentas e fontes externas |
| STDIO | Comunicação por entrada e saída de um processo local |
| Streamable HTTP | Transporte MCP baseado em HTTP |
| OAuth | Protocolo para autorização delegada |
| GAQL | Linguagem de consulta da Google Ads API |
| MCC | Conta gerenciadora do Google Ads |
| TCO | Custo total de propriedade e operação |
| ADR | Architecture Decision Record — registro de decisão arquitetural |
