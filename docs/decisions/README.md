# Registros de decisão arquitetural (ADRs)

Este índice registra decisões e suas motivações, distinguindo **por que** de **como implementar**.

- [ADR 0001 — Streamable HTTP](0001-streamable-http.md): independência da máquina local e potencial de reutilização.
- [ADR 0002 — Cloud Run](0002-cloud-run.md): viabilidade institucional e caminho documentado.

Decisões podem ser revistas diante de novos requisitos, custos e controles.
