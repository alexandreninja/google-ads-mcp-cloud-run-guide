# Documentation index

This is a step-by-step route for people who work in marketing and are still getting to know cloud services. Each step has a checkpoint: confirm it before moving on. Commands are examples to review and adapt; some enable services, create or change resources, and may incur charges.

| Step | What to check | Guide |
| --- | --- | --- |
| 1. Prepare | Project, billing, permissions, APIs, and Google Ads API access | [Prerequisites](getting-started/PREREQUISITES.md) |
| 2. Understand the setup | What will be published, which server version will be used, and which resources may be created | [Deploy to Cloud Run](getting-started/DEPLOY.md) |
| 3. Set up sign-in | OAuth client, redirect URLs, and secure storage for secret values | [OAuth and Secret Manager](guides/OAUTH-AND-SECRETS.md) |
| 4. Publish and check | HTTPS service, authentication, MCP tools, and a query to an authorized account | [Deployment](getting-started/DEPLOY.md) · [Validation](guides/VALIDATION.md) |
| 5. Operate | Errors, costs, logs, updates, and maintenance | [Troubleshooting](guides/TROUBLESHOOTING.md) · [Costs](guides/COSTS.md) · [Operations](guides/OPERATIONS.md) |

The deployment guide tells you when to pause to set up OAuth and review the tools included in your chosen version. Do not skip these points: server versions and organizational settings can differ.
