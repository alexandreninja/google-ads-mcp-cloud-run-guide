# Contribuindo

São bem-vindas correções de documentação, links, exemplos seguros e explicações para iniciantes.

1. Abra issues sem credenciais ou dados pessoais.
2. Faça mudanças pequenas e verificáveis.
3. Distinga **testado**, **documentação oficial** e **hipótese**.
4. Nunca inclua dados institucionais, tokens, segredos, URLs privadas ou exports.
5. Defeitos do software oficial devem ser relatados prioritariamente no [repositório do Google](https://github.com/googleads/google-ads-mcp/issues).

A documentação é principalmente em português do Brasil; nomes de produtos e identificadores seguem os termos oficiais.
