# Contribuindo

Correções de exemplos, links e documentação são bem-vindas.

- Preserve comandos reproduzíveis e dados fictícios.
- Valide mudanças antes de enviá-las.
- Não publique segredos, tokens nem dados de contas.
- Para defeitos do servidor-base, use as [issues do projeto oficial](https://github.com/googleads/google-ads-mcp/issues).
